## 📖 About

🔹 **Terraria — Auto Trash** is a powerful tool built to help you automatically delete unwanted item drops in Terraria by configuring a trash filter list. No more inventory filling with common rocks and broken armor — Auto Trash silently discards configured junk items.

🔸 Whether you're a seasoned professional or just getting started, **Terraria — Auto Trash** delivers a clean, intuitive experience packed with everything you need — right out of the box. Join thousands of users who've already streamlined their Terraria modding workflow. Download now and get started in minutes. 🚀

## 🚀 Features

| Feature | Description |
|---------|-------------|
| Filter List | Maintain a list of items to automatically delete on pickup |
| Category Filters | Quickly filter entire item categories like common ores or low-tier consumables |
| Whitelist Mode | Alternatively configure which items to KEEP and trash everything else |
| Safe Override | Hotkey to temporarily disable auto-trash when farming specific drops |
